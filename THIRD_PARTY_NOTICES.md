The WebGL2 wave renderer and spline pipeline in `src/scripts/xmb-wave.js`,
the sparkle particles in `src/scripts/xmb-particles.js`, and the Canvas 2D wave
in `src/scripts/space.js` adapt code from
[linkev/PlayStation-3-XMB](https://github.com/linkev/PlayStation-3-XMB).
The WebGL2 version keeps the original spline pipeline and wave shaders, with
transparent rendering and theme colors for this site.
